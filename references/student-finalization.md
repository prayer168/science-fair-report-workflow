# 研究完成後以學生觀點統一定稿

使用者要求：等整個科展完成，含數據分析、討論與結論，再統整每個標題的內容。研究進行中不提前宣稱完成。這份指南在定稿時使用；先確認當次學生資料、研究範圍與原共編最新內容。

## 學生敘述與證據

- 全文以學生研究者的「我們」敘述，清楚呈現我們注意到什麼、想問什麼、如何試驗、看見什麼、如何理解、還有哪些限制。用符合學生年段但精確的文字，不套用學術論文腔，也不刻意裝幼稚。
- 研究動機從學生實際提供的生活經驗、觀察或疑問出發，再連到研究問題。缺少真實經驗時保留待學生補充，不能捏造「放學時遇雨」「在校園發現」等情節、對話或感受。
- 題目、摘要、各項研究目的與實際完成的實驗一致。未完成或已取消的項目如實說明，不能只為敘事完整補寫成已執行。
- 文獻回顧保留必要的專業來源，用學生能理解的話說明「我們查到什麼」「因此怎麼設計」，不堆術語或與研究無關的論文。查資料、使用第三方工具與本組自行開發的成果要分清楚。
- 方法敘述我們實際使用的設備、數量、規格與操作，不把建議值當成實際值；與原始紀錄、照片、圖示及設定版本核對。
- 結果依原始資料重算分母、單位、平均／中位數／變異及需要的圖表；失敗、缺測、未反應與排除理由保留。重複操作不能當作多台裝置／多個獨立樣本，不因想得到顯著差異而選擇分析方法。
- 討論以學生角度解釋數據，例如「我們發現……，可能與……有關，因為……；目前還不能確定……」。分清觀察、推測與文獻解釋，不直接把相關寫成因果；不無據歸因人為誤差。
- 結論逐項回答目的，具體寫出測試條件與資料支持的發現，學生能口頭解釋。避免「成功證明」「完全可靠」等超過實驗範圍的話，不新增結果章未出現的數據。

## APA 與文獻正確性

定稿當下查核 APA 官方最新版本與官方範例，不永遠鎖定某一版。2026-11-25 查核時官方仍提供第七版：

- [APA 官方手冊](https://apastyle.apa.org/products/publication-manual-7th-edition)
- [官方參考文獻範例](https://apastyle.apa.org/style-grammar-guidelines/references/examples)
- [書目基本要素](https://apastyle.apa.org/style-grammar-guidelines/references/basic-principles)

依來源類型核對作者、日期、原題名、期刊／出版者、卷期頁碼／文章編號、DOI／URL；內容引用須確實支撐該敘述。正文作者年份與末尾書目雙向對應，同作者同年標記一致。作者名稱縮寫若用在正文，要先定義；不能讓正文的組織簡稱與書目無法對應。

按官方範例檢查排序、斜體、懸掛縮排與標點；DOI 使用正確連結，沒有日期不捏造日期，擷取日期只在適用來源使用。APA 用於引用與書目；全書紙張、標題、字級及行距以當屆科展規定為準，不直接套整套 APA 論文版面。

## 當屆規定、篇幅與編排

正式定稿必須上網查核當屆、當地科展的正式計畫、作品說明書範本與補充公告；準備全國賽時另核對全國規定。記錄發文日期、版本、適用賽事及條文位置。若只有前一屆資料，標成暫參考，不能宣稱已符合下一屆全部規定。

可從[臺南市科展平台](https://sf.tn.edu.tw/)及[國立臺灣科學教育館實施要點](https://twsf.ntsec.gov.tw/Article.aspx?a=38&lang=1)找官方依據。使用者要求正式作品書最多30頁，列為固定定稿上限；若當屆限制更嚴格則採較嚴者，不能自行放寬。其餘項目逐項讀當屆文件後檢查：

- 紙張尺寸、方向、邊界、字型字級、行距、頁碼與圖表清晰度。
- 頁數／字數／摘要字數限制及計數範圍，封面、封底、目錄、附錄及圖表是否列入。
- 標題順序及層級、項目符號與縮排；需要「壹、一、（一）、1、（1）」時依官方範例整齊編排，不把任意項目符號混在標題層級。
- 匿名要求、學生／教師姓名與照片是否可出現；共編工作稿的分工註記若不符匿名規定，正式送件稿須依規定處理。
- 提交檔案格式與大小限制；圖片壓縮後仍須看得清楚，不能只降低可讀性來達到大小限制。

篇幅超出時先刪重複與不相關文字、濃縮程序並合併合理圖表，保留支持結論的必要方法與證據，不能只把字體縮小或把超出內容塞到不合規附錄。研究進行中的完整可編輯觀察表／詳細實作內容依使用者指示保留；若正式送件限制與「全部放在同一份」無法同時滿足，先完成可檢視的精簡方案，說明具體取捨再請使用者決定，不能默默丟掉原始資料。

以最終PDF實際計數驗收30頁限制，不看舊頁碼。封面、封底、目錄的扣除需有官方依據與逐頁清單；未確認時全頁計入，其他內容不可自行排除。執行 `scripts/check_report_pages.py` 並保存結果；超過30頁返回精簡、排版與渲染，通過後才可標示正式定稿。

## 紅字補充說明

與學生正式研究敘述無直接關係、但確實需要保留的教師提醒、編輯註記、待補提示或額外說明，使用 Word 原生文字色彩 `FF0000`，保留可編輯。沒有必要的說明直接刪去，不為了紅字而新增旁白。

正文的研究方法、真實結果、限制與引用保持正常文字；不得把資料矛盾或缺漏只塗紅就視為已解決，也不能把教學提示當成研究發現。紅字說明仍列入當屆規定要求的字數／頁數，不因是補充就忽略計算。送件如另有字色或內容限制，明確指出條文與使用者紅字需求之衝突，提出具體稿件方案，不自行宣稱兩者皆符合。

## 定稿驗收

逐章完成學生觀點改寫 → 對原始資料與全文引用 → 核對當屆字數、頁數、項目層級與版面 → 檢查紅字分類 → 全書渲染逐頁檢查 → 修正並重驗 → 更新同一共編 ID → 核對所有學生權限與雲端原始檔內容。完整性報告區分文件完整、資料充分與送件規定符合性，分別列通過／未通過／待確認。
